# 🐍 Python Masterclass Landing Page

A modern, responsive landing page designed for a Python Masterclass course. This project was built using HTML, CSS, and JavaScript, with a focus on clean UI, responsiveness, and user-friendly design.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile devices
- Modern hero section with call-to-action buttons
- Course highlights and learning outcomes
- Interactive pricing section
- Smooth scrolling navigation
- Font Awesome icons
- Google Fonts integration
- Clean and organized code structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome
- Google Fonts

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/Vyshali05/python-masterclass.git
```

2. Navigate to the project folder:

```bash
cd python-masterclass
```

3. Open `index.html` in your browser or use the **Live Server** extension in Visual Studio Code.
